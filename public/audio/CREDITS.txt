The Bloom Wars — public/audio/ credits
========================================
Replaces the procedurally-synthesized placeholder audio (9 Sep 2026, night)
with real CC0 (public domain) recordings, fetched live via the Chrome
extension on 9 Sep 2026. All sources are Creative Commons Zero — no
attribution is legally required, but it's listed here so the source is
never lost and so any file can be swapped again later.

hub_ambient.ogg
    Source: "Scifi City - Ambient Loop" (busy_cyberworld.ogg) by TinyWorlds
    https://opengameart.org/content/scifi-city-ambient-loop
    License: CC0
    Note: the source page itself says it "loops (kinda) seamlessly" — a
    short fade-in/out was applied at the seam here, not a true crossfade
    loop. Worth a listen before assuming it's glitch-free on repeat.

battle_ambient.ogg
    Source: "Sci-Fi Background noise" by Spring Spring / Spring Enterprises
    https://opengameart.org/content/sci-fi-background-noise
    License: CC0
    Note: same fade in/out treatment as hub_ambient, same caveat.

All files resampled/converted to 44100Hz stereo Ogg Vorbis to match the
project's existing pipeline — same filenames as before, so no code
changed, only the binaries under this folder.

tools/synth_placeholder_audio.py (the earlier procedural-synthesis script)
is left in the repo as-is — it's how these files were generated before
tonight, and it's still there if any of these real assets need a quick
synthetic stand-in again for some reason.
