Thanks for downloading. A few things before you dive in.

WHAT "EARLY ACCESS" MEANS HERE
The campaign (Warden Company, 36 missions) is finished and playable start
to finish. What's still moving: mission-by-mission balance, and the art —
right now every unit and building on screen is a placeholder geometric
shape, a deliberate choice to get the tactics and systems built first, not
a bug. Free updates are coming (a whole second campaign, House Amaranth,
among them) — see the itch.io page for what's planned.

FIRST LAUNCH ON WINDOWS
Windows will probably show an "unknown publisher" warning (SmartScreen).
That's because this build isn't signed with a certificate yet, not
because anything is wrong — click "More info," then "Run anyway."

YOUR SAVE
The game saves automatically as you play. Since permadeath is real here,
it's worth knowing Options has an EXPORT SAVE / IMPORT SAVE pair — export
writes your current campaign out as text you can paste somewhere safe
before a reinstall or an update, in case anything ever goes wrong with the
save on this machine.

FOUND A BUG?
Options → COPY STATS + BUG REPORT TO CLIPBOARD copies your game version,
your mission history, and an install id — paste that (plus what you were
doing) into a bug report. Where to send it: [Discord invite link goes
here once the server is public] or wherever you got this build.

REFUND
If it won't run on your machine, say so and you'll get your money back.

Nothing in this game phones out or uploads anything on its own. Third-
party credits are in THIRD_PARTY_NOTICES.txt, alongside this file.
