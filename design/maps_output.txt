NOTES -- real differences found against the live engine, flagged not fixed
==============================================================================
1. Blockhouse wall, flight cost. The original legend prints 99 (passable
   to flyers at an absurd cost). The live src/data/tiles.ts sets flying to
   Infinity and carries an explicit comment -- 'Impassable to everything,
   flyers included. GDD Sec.4.6 / Data Pack Sec.7.3'. Those disagree. This
   script keeps 99 so its output still matches the original artifact it is
   being checked against; the engine is almost certainly the correct one.
   Maxime's call which is canon -- if the engine wins, change the 99 above
   to IMPASSABLE and update the ORIGINAL_LEGEND row to match.

2. Deploy pad display name. Legend says 'Deploy pad (player)'; tiles.ts
   says 'Deploy pad'. Cosmetic, no gameplay effect. Not changed.

3. The 'dock' tile (Mission 22 Protect Asset, 25 Aug 2026) exists in
   tiles.ts but postdates the original script, so it is excluded from the
   legend comparison above. It IS registered in this script's tile table,
   so a future map using 'D' will validate rather than be rejected.

4. Tile effects this script does not model: bloom_mat's 5 turn-start
   damage, deploy's 20 turn-start repair, ridge's +1 Reeps range. They
   live in tiles.ts and matter in play, but none of them affect map
   *validity*, which is all this script is for.

5. maps.py only covers the four archived Team One maps -- the same four
   the original covered. The live Amaranth campaign's 36 maps live in
   src/data/mapsAmaranth.ts and were generated by ad hoc per-batch
   scripts, not by this one. Bringing them under this script would be a
   real piece of work and a real scope decision, not a quiet extension.
