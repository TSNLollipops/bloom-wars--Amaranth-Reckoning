## What shipped

**Tier is now a capacity ladder, not just a stat ladder** (`src/data/frameSystems.ts`, `FRAME_TIER_CAPACITY`). Stats per tier are untouched — `combatTables.ts`'s `TIERS` was not edited, so nothing in the combat sim needed re-tuning. What each step also grants now: one weapon mount until tier C, two from C up; a Draw budget of 2/3/4/5/6/8/10 for G/F/E/D/C/B/A. S (Heirloom-grade, never purchasable) reads as A's row, on the same "S sits above A" reasoning every other S-tier special case uses — Claude's call, the doc's table doesn't have an S row.

**Second weapon mount.** From tier C a pilot carries two weapon branches into a mission at once. The semantics chosen, since the doc says "second mount" and stops there: both branches are fully live. Passive attack bonuses stack, granted abilities from each are on the action bar, on-hit effect lists union, and attack range is the widest window across the archetype base and every equipped branch's override (Scattershot's range change still applies when Scattershot is one of the two). A refit's own `attackRange` replaces the archetype base before the branch merge. The old single-field `equippedWeaponBranch` still exists and mirrors mount 1, so every existing save loads unchanged and every pre-6-Sep code path that read the single field keeps working. New field `equippedWeaponBranches: string[]` is the source of truth from here on.

**Sixteen systems across six families** — Frame (Reinforced Plating, Spall Liner, Sealed Cockpit, Redundant Actuators), Drive (Sprint Cell, Low-Profile Gait, Bloomwalkers), Sensor (Signal Booster, Seismic Tap), Ordnance (Focusing Optics, Shredder Rounds, Overpressure Regulator), Support (Field Repair Kit, Salve Drone), Salvage (Wellroot Filament, Heartwood Graft). Each has a Draw cost of 1, 2, or 3. Owned permanently once bought (personal points, `draw × 60` placeholder), equipped freely within the frame's Draw budget. Four are pure stat deltas (Reinforced Plating, Sprint Cell, Signal Booster, Heartwood Graft) summed as one more additive term in Data Pack §5.1's order of application (base → tier → mek → branch → systems+refit, `frameStatBonus()` in `engine/frameSystems.ts`). The other twelve needed a real engine hook each — the doc's "pure numbers, zero new engine work" label was optimistic for most of the bold list, and the count of hooks is the honest measure of what this build actually touched: Spall Liner halves counter damage taken; Sealed Cockpit skips turn-start environmental damage for mechs; Redundant Actuators makes a centauroid pay bipedal movement costs everywhere; Low-Profile Gait adds a terrain star when the tile already gives at least 2 (deliberately not on open ground — a tuning fix found by the tests, see below); Bloomwalkers makes bloom-mat cost 1 move; Seismic Tap reveals burrowed Bloom within 3 tiles; Focusing Optics adds +8 attack at range; Shredder Rounds ignores 25% of defender DEF; Overpressure Regulator multiplies the first attack of the mission by 1.4, then is spent; Field Repair Kit multiplies Repair output by 1.25; Salve Drone is a second regen aura (+3/turn, radius 1) that the existing Munti aura code now picks up as one more source; Wellroot Filament regens 8 on bloom mat and ignores mat acid.

**Eight A-tier refits**, one per path, permanent, `FRAME_REFIT_COST = 350` placeholder: Meeps Skirmish Frame / Breacher Frame, Tank Bastion / Ram Frame, Reeps Battery Frame / Skirmish Battery, Munti Aid Station / Vanguard Medic. Bastion widens the overshield radius by 1. Ram Frame lets the Tank charge after any 2+ tile move (reusing the centauroid charge flag). Battery Frame sets attack range to 2–5 but the unit can't attack after moving; Skirmish Battery is 2–3 with no such restriction. Aid Station pushes repair range +2; Vanguard Medic pulls it to 1. Gated to tier A (S included), one per pilot forever.

**Salvage supply line, silent counter.** `CampaignState.hostileKillsByArchetype` starts recording on every Debrief from the moment this ships (`recordHostileKills`, wired next to the existing on-hit-effect recorder). Each salvage system names a source archetype and a kill count; the shop shows `LOCKED have/needed` until it's met. A non-Runemaster loadout pays +1 Draw on salvage systems (`[2+1 Draw]` in the panel), per §7. If the source archetype never appears anywhere in the side's campaign (waves or spawn events), the system is hidden entirely rather than shown as a lock that can never open — which is exactly Heartwood Graft's situation today, see the flagged items below.

**The equip screen.** `src/scenes/shop/FramePanel.ts`, `showFrameOverlay()`. Opened from the Shop's new `[ FRAME · Draw x/y · mounts n/m ]` link and from the Transporter Pad's `[ frame · Draw x/y ]` link. Header shows name, points, tier, Draw used/capacity, mounts, current loadout. MOUNTS section toggles owned branches into M1/M2. SYSTEMS by family with BUY (cost) / INSTALL (n Draw) / INSTALLED / LOCKED buttons. REFIT shows both path options as preview text before tier A, two REFIT buttons at A, and a permanent line after purchase. The Shop's own weapon-branch row is mount-aware now (`[M1]`/`[M2]` tags, `MOUNT`/`EQUIP`, `(MOUNTS FULL)` disabled). The Transporter Pad's branch-cycle click opens the Frame panel when the pilot has two mounts, cycles mount 1 otherwise, and the track line reads "Weapon: A + B".

## What the doc said versus what got built — three honest discrepancies

Verified against the design doc's actual current text before writing this, not from memory.

- **The count.** §5's summary line says "24 systems, of which 13 are pure numbers." The bulleted list under it holds 32, 18 bold. This build went from the list, not the line. The line drifted.
- **Three "pure-number" systems describe mechanics this engine doesn't have.** Field Repair Kit ("one extra Repair charge per mission") — Repair has no charges and no cap, same finding Field Doctor hit on 1 Sep; built anyway as +25% Repair output, the closest real lever. Stabilizer Struts ("stationary repair also works if you moved 1 tile") — there is no stationary-repair rule; `MEK_TRACK_EFFECTS.fieldwright.stationaryHeal` is a data field nothing reads. Crash Foam Lining ("restock at 75% HP when a Fabricator part redeploys you") — the Fabricator redeploy is explicitly unbuilt. **Those two are not built**, listed in `UNBUILT_DOC_SYSTEMS` so nothing forgets them. Reinterpreting either would have meant inventing a mechanic, not transcribing one.
- **Heartwood never spawns.** `bloom_heartwood` has zero waves in either shipped campaign; it survives only in the archived Team One slice. Heartwood Graft is built and gated as written, and the hide rule above keeps it off-screen. The doc's own §7 salvage list doesn't include Heartwood either — §5f and §7 disagree with each other.

Also reinterpreted, smaller: Aid Station's "+2 repair range" is applied as a delta on whatever the healer's branch already gives (Rapid Response's own range included), not a fixed number.

## Flagged for Maxime — things this build decided that are yours to overrule

- **Second mount = both branches fully live, effects stack.** The doc never specified. The alternative (a "primary" and an "offhand" with reduced effect) would have been a second mechanic on top of the first. Stacking two passive attack bonuses on one pilot is the balance risk here; nothing has been sim-run against it.
- **Shredder Rounds + Rail Lance vs a Tank** is additive: 25% + 25% = 50% DEF ignored, capped at 90%. Could be multiplicative or non-stacking instead.
- **Runemaster burrow detection is still not wired.** Seismic Tap is the only *passive* burrow detection today (Sensor Sweep still reveals actively). `data/meks.ts` gives the Runemaster primary track `burrowDetection: true`; nothing reads it. Same category as `stationaryHeal` — a data field with no consumer — and it means the design doc's "Seismic Tap is deliberately weaker than the Runemaster's" rule is currently inverted.
- **The sim bot doesn't know Battery Frame** can't attack after moving. `playerAi` will occasionally move a Battery Frame Reeps and then fail to fire. Harmless in the shipped game (a human sees the refusal message), wrong in `npm run sim` batches for any pilot carrying that refit.
- **Saves from before today** start the salvage counter from their next Debrief, not retroactively. A player 30 missions in who's killed a hundred Wellroots starts at zero. Acceptable for a pre-EA build; worth knowing.
- **The harness's salvage model is simpler than what shipped** (a flat 15-kill threshold, now documented as superseded in `frameSystemsEconomyParams.ts`; the real gates are per-archetype and currently 1 kill each). The harness's cost and capacity constants now import from the shipped data file, so those can't drift, but its salvage timing is still a placeholder.
- **Heartwood Graft** — add a Heartwood encounter, re-source the graft to a Bloom that does spawn, or leave it hidden. Content decision.
- **Stabilizer Struts and Crash Foam Lining** — build the mechanics they depend on, reinterpret them, or cut them from the doc.
- **Every number is a placeholder**: 60 pts/Draw, 350 for a refit, every system's stat delta and Draw cost, all eight refit numbers, the 1-kill salvage gates. `npm run sim:economy` can test the cost side. Nothing tests the combat side of a stacked loadout yet — that's a `combat_sim.py` job when you want it.
