# Playtest note — Mission 9, flagged 29 Aug 2026

**Not investigated further, not fixed — capture only. Tally mode, per this session's standing instruction.**

Maxime, playtesting Mission 9 (Cut Off, survive_n_turns) himself: the mission can be completed without fighting at all. His own read, not framed as a complaint: "but if you want point for later better kill bloom" — treating it as a legitimate risk/reward choice (turtle safely for a guaranteed clean win, or engage more Crawlmass for more points toward later gear/tier purchases) rather than something that needs fixing.

**Worth knowing: this is already a documented, previously-investigated finding, not a new discovery — his playtest just confirmed it independently.** `Bloom_Wars_Master_Index.md` already records a hand-played test of exactly this mission: hold the deploy corner, never step within 3 tiles of either fixed Gallcyst turret, and "survive 10 turns" degenerates into real combat for the first 3 turns (a few Crawlmass wander into vision early and get killed) followed by total silence for the remaining 7, since the rest of the Crawlmass never get close enough to engage at all (`intelligence: "reflexive"` units only act once they can see a target). That prior pass's own conclusion reads it as the test-AI-vs-informed-player gap again, the same root cause already on record from the Mission 20 investigation — a real, informed player finding a genuinely safe path an AI batch-run wouldn't reliably find or exploit the same way. Since Maxime's own framing treats the tradeoff as acceptable rather than broken, this probably doesn't need action on its own — recorded mainly so it doesn't get treated as a fresh bug report if it comes up again later.
