NOTES
==============================================================================
1. This script's tile-cost table is copied verbatim from design/maps.py,
   not imported -- see the file header on why the two scripts stay
   independent. If maps.py's table ever changes (e.g. the blockhouse-wall
   flight-cost question flagged in its own NOTES), this file needs the
   same edit made by hand, or the two will quietly disagree.

2. No per-map difficulty/balance judgment is made here, same honest limit
   as maps.py. This confirms the 36 maps are well-formed and physically
   playable -- not that they are fun, fair, or correctly tuned.

3. Team One's four maps are untouched by this file. design/maps.py, its
   own frozen reference, and its own generated output are exactly as
   they were before this script existed.
