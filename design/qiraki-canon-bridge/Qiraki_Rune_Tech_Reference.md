# THE QIRAKI FILES — Rune-Tech Reference

*Part of the Qiraki files. Living document, add new entries as they get taught, used, or invented across drafting. Core grammar summary here for quick reference, full detail and reasoning lives in Qiraki_Technobabble_Glossary.md, don’t let the two drift apart.*

## Core grammar (summary, see glossary for full reasoning)

- **Peg** — a connection point, term reused straight from the childhood game.

- **Trace** — a line drawn peg to peg. Direction matters as much as shape, same pegs traced backward is a different instruction, not a mirror.

- **Knot** — three or more traces meeting at one peg, functions as an operation, not just a connection.

- **Circuit** — multiple linked patterns read in sequence.

- **Circle** — a closed, self-referencing loop, the mechanism behind constructs that run without further input. Root of Heirloom-grade effects at the extreme end.

## Theoretical grounding, real science mapped to the grammar

Goal: anchor as much of the curriculum as possible in genuine, established theory before any tier requires invented science. Ordered by when a cadet would actually encounter it, tracking where real theory runs out.

**Pegs and traces = graph theory.** This isn’t a loose metaphor, it’s the literal underlying math. A peg is a node, a trace is a directed edge, since direction matters independent of shape (already locked). “The First Pattern” is a cadet’s first legible directed graph. Genuinely real, genuinely teachable, no invention required.

**Knots = logic gates.** Three or more traces meeting at one peg, functioning as an operation rather than a connection, maps directly onto boolean logic, AND/OR/NOT gates built from how many inputs converge and what the output does. This is the actual foundation of real digital computing, not flavor text.

**Circuits = algorithms / finite state machines.** A sequence of linked patterns read in order is functionally a program, or a state machine moving from one condition to the next based on input. Diagnostic Ping and Structural Read (already catalogued above) are both simple real- world-analogous algorithms once framed this way.

**The panel flagging a wrong trace = error-checking.** Real information theory, the same underlying principle as a checksum or parity check, verifying that what was actually traced matches what was expected before letting it propagate further. Worth keeping this framing consistent if the mechanic ever needs explaining on the page again.

**Circles = feedback loops / control theory.** A closed, self- referencing loop that runs without further input is precisely what a real control system is, a thermostat, an autopilot, anything that checks its own output and adjusts. Genuinely real engineering, not invented.

**“************Building a rudimentary AI************”**** ****= weighted, trainable networks.** This is where it gets genuinely exciting rather than just consistent: the already-locked mechanic of a connective AI gaining experience and leveling up from use maps directly onto real machine learning, connections strengthening through repeated exposure, exactly how an actual trained model improves. The curriculum’s advanced material, building a rudimentary AI given access to a mindblock, is a simplified, diegetic version of training a real neural network. This single mapping is probably the most satisfying one in the whole system, since it means Trav’s symbiosis accelerating Zeteii’s growth (already locked) isn’t just narrative flavor, it’s a real training-signal-strength analogy readers with any technical background will recognize immediately.

**Where real theory runs out, LOCKED boundary:** Sovereign- and Heirloom-grade effects, battlefield teleport, ethereal restraint chains, extreme-tier circle constructs. No real-world grounding exists for these and none should be invented to force one, they’re explicitly flagged elsewhere as “bullshit tech” by design. The curriculum should carry a cadet from real graph theory through real machine-learning-adjacent material for the vast majority of their education. The break into invented science happens exactly once, at the extreme top, and should stay visibly, deliberately different in kind from everything below it, not a smooth continuation of the same logic.

## Rune-form: the visual system (LOCKED 2026-08-15)

*Answers the open item both Qiraki_Concept.md (****“************Rune-system design, visual grammar… remains an open invitation************”****) and Qiraki_Technobabble_Glossary.md (****“************exact rune-set, grammar, or visual system not yet designed************”****) were carrying. Confirmed 2026-08-15: Maxime reviewed this material via a reader-facing primer built from it and signed off on using it to build up the files. Locking it here.*

**The board.** A fixed 3x3 grid of nine pegs, numbered like a keypad, 7-8-9 across the top, 4-5-6 the middle row, 1-2-3 the bottom. Cheap to notch into a wood scrap or mold in plastic, exactly the toy a subsidy- dependent family could actually afford to keep by the door, consistent with the academy’s stated poor-and-working-class population. Year 1 literacy work never leaves this board, a given pattern uses whichever of the nine pegs it needs, not all nine at once. Larger boards get introduced once later coursework genuinely needs more than nine points to say something (see year-by-year, below), keeping the same keypad- style numbering, just extended.

**Traces are straight lines, no exceptions.** Already locked functionally, locking it visually too, since it’s the thing that actually generates every shape below it. A trace is peg to peg, shortest path, no curves, ever. Real grounding, not just a style pick: this is the same reason carved runic alphabets (Elder Futhark, Ogham) are built entirely from straight strokes, no bowls or curls in either system, because a straight cut holds against wood grain and a curved one splits it. The peg-board’s version of the same physical constraint: a trace is a string or a light-line snapping taut between two fixed points, it can’t curve if it wanted to.

**What a straight-line-only, nine-point system actually produces.** Angular compound shapes, every one, because that’s the only kind of shape the substrate can generate. Simple rune-forms read as a single mark, a slash, a chevron, a bar. Denser ones start looking like fragments of familiar alphabets purely as a side effect of geometry, not by design, the same reason Elder Futhark superficially resembles Latin letters despite the two not being related the way people usually assume. There’s only so many ways to connect a handful of dots with straight lines before every writing system that’s tried it reinvents the same handful of shapes.

**Deliberate choice, worth stating plainly:** this leans into shapes the grammar itself generates rather than dressing rune-forms in an existing human script, Kanji, Arabic, Devanagari, or otherwise. Borrowing a real writing system to make alien tech read as mysterious usually ends up treating that language as decoration rather than language, and it would sit strangely next to the discipline this Style Guide already holds every species to, no caricature, sophisticated internal logic, nothing borrowed just to look foreign. A shape generated by the actual mechanic, pegs, straight traces, knot convergence, earns its strangeness the same way the curriculum earns its realism elsewhere.

**Radicals.** Once a sub-shape gets reused across more than one rune- form because it keeps carrying the same underlying meaning, it’s a radical, same principle real logographic systems run on: Chinese characters build compound meaning from reused component radicals, Egyptian hieroglyphs used determinatives the same way. A rune-form’s full shape should generally read as smaller, already-known pieces once a cadet has enough of them banked, not a wholly new shape every single time. More teachable inside the story, more consistent to keep writing across seven books. Starting set below, add to this list the moment a new rune-form reuses a shape enough to earn radical status.

- **The Single** — one trace, peg to peg, no knot. The base unit, “one thing happens.” A plain stroke, diagonal or straight.

- **The Fork** — a knot where exactly three traces converge. The shape behind the panel’s own “fist, not a flat hand” line in Ch.2. Three lines meeting at a point, reads like a narrow peak or an asterisk missing an arm.

- **The Gate** — a knot where four or more traces converge, reserved for anything conditional or branching (Year 4+, see below). Denser than a Fork, reads like a small starburst, distinguishable by weight alone before a cadet’s even counted the lines.

- **The Loop** — a circuit that closes back on its own starting peg. The literal miniature shape of a circle-construct. Doesn’t need to look round, just closed, the closure itself is the tell.

**Reference notation used below:** peg positions given as keypad numbers 1-9. Trace order given as a sequence, e.g. 7->3->9. Knots called out by name (Fork/Gate) and which peg they sit on. Shape description given in plain visual language, something a reader could picture without seeing an actual diagram.

**Where this leaves the Heirloom question, tying back to why any of this matters:** if a rune-form is fundamentally a request, trace this peg, then this one, in this order, then everything below Sovereign/ Heirloom tier is a request the board’s actual, physical nine (or however many) pegs can honor. A Heirloom-tier construct’s real strangeness, mechanically, not just narratively, is that it requests a peg that isn’t there and gets it anyway. Full writeup under Heirloom- tier effects, below, but worth stating the principle up here since it’s the thing that makes rune-mastery read as more than a coding class, the entire curriculum is children learning to ask reality for things using a fixed, honest vocabulary, and the one tier that sits outside any child’s reach is the one where the vocabulary stops being honest and the request gets answered anyway.

## Two registers: rune-script and rune-form (LOCKED 2026-08-15)

*Direct response to a real correction, integrating the coding half shouldn’t have crowded out the language half. Rune-patterning has always been described as**** ****“****part written language, part programming logic****”**** ****(Qiraki_Technobabble_Glossary.md), and everything built above this session leaned hard into the coding half, functional effect-runes, knots as operations, curriculum as engineering. This section is the language half, built on the exact same board and the exact same straight-trace rule, not a second invented system bolted on beside it. Confirmed 2026-08-15 alongside the visual system and the alphabet, below.*

**The split, and why it’s a split rather than one undifferentiated pile of shapes.** Simple, no-knot shapes (Singles, and short paths of two or three Singles with no convergence) form **rune-script**, an actual phonetic alphabet, letters that spell real words the way any alphabet does. Anything with a knot, Fork, Gate, or Loop, stays **rune-form**, the functional/technical register already built out above. A reader (in-world and out) can tell which register they’re looking at by density alone before they’ve worked out what anything means, plain lines are language, anything with a convergence point is doing something. Real-world grounding for the split itself: Japanese does something structurally similar, kanji carry dense logographic content, kana carry lighter, simpler phonetic grammar, and a fluent reader tells them apart on sight, not by translating first.

**What this makes rune-form actually mean, once rune-script exists alongside it.** A rune-form like Diagnostic Ping or Seal isn’t just a spell, it’s also a word. Written on a wall, a crate, a page, with no active board reading it, “Seal” is inert, a logogram meaning “locked,” exactly as legible and exactly as harmless as the word “locked” printed on a sign. Traced on an actual active peg-board or access panel, the same shape executes. This isn’t two different objects, it’s one shape read two different ways depending on context, the same relationship a barcode has to a human eye versus a scanner, or a punch card has to a person holding it versus a loom reading it. Nothing invented to make this work, it falls straight out of treating rune-form and rune-script as one grammar rather than two.

**Why this is the whole Coalition’s script, not just this academy’s.** Humanity was first to rise as a spacefaring civilization and earned alliance with the COE’s other species on that basis, already locked elsewhere. Rune-script piggybacks on that same historical fact the way real lingua francas actually spread, not because every culture happened to invent the same alphabet, but because whoever’s infrastructure gets adopted first ends up carrying everyone else’s paperwork afterward, Latin script riding Roman administration, English riding first British then American infrastructure, Chinese characters riding Chinese political and cultural weight across Korea, Japan, and Vietnam for centuries regardless of how differently those languages actually sound. Rune-script most plausibly spreads the same way, COE-wide administration, trade, the academy pipeline, and the gate network’s own paperwork all standardized on it once humanity’s version of “connective tech” became the thing the whole Coalition’s daily infrastructure quietly depended on. Spoken language stays genuinely diverse, homeworld to homeworld, that’s not touched by any of this. The written script is what’s shared, the same way script and speech already come apart in plenty of real, unrelated languages.

**Already proven out on the page, not just theorized:** Vrassik, Hiopi, is in Trav’s cohort from Book 1 (Ch.2’s classroom scene doesn’t name him specifically, but he’s introduced this same book per Qiraki_Concept.md’s own Book 1 summary, “First friendships form, Denic, Ilyen, Corw, Vrassik all introduced”), sitting through the identical rune-literacy class human cadets sit through. He almost certainly doesn’t have the folk peg-game head start Trav and Denic have, no reason a Hiopi household would own that specific human toy, which is worth keeping in mind if a scene ever wants to show him working harder at the literacy stretch specifically for that reason, a small, earned, unstated cost of a shared script that started out belonging to somebody else’s childhood.

**In-world name.** **Common Script** is the COE’s own flat, bureaucratic term for it, admin paperwork, trade manifests, and school curricula call it that. Older or poorer populations, closer to the folk-game origin, sometimes still call it **peg-writing** informally, same class-conscious texture already running through the Cradle Circle material, the people closest to where it came from are the ones least likely to use the official name for it.

## Literacy timeline: does a year actually deliver reading? (LOCKED 2026-08-15, DEF-31)

*Direct response to a real gap. The Year 1 bullet above claims a full year gets a cadet from zero to literate, but only 6 of the 21 rune-script letters (AH, EH, T, D, W, L) come from the Foundational Nine, and the bullet’s own**** ****“****alphabet before sentences****”**** ****framing left open whether cadets actually finish the year reading, or just finish it knowing letters. Resolved below, grounded rather than asserted, same discipline as the Lally et al. habit-formation fix.*

**Real-world grounding.** Seymour, Aro & Erskine (2003, *British Journal of Psychology*, “Foundation literacy acquisition in European orthographies”) tested reading acquisition across thirteen European languages and found that children learning transparent, one-shape-one-sound orthographies (Finnish, Italian, Spanish, German, Greek, and most others tested) become accurate, fluent foundation-level readers before the end of their very first school year. English, whose spelling is famously inconsistent, took roughly two and a half times longer to hit the same benchmark. The deciding factor wasn’t the children’s age or general intelligence, it was how honestly each spelling system matched its own sound system.

Common Script is more regular than any language in that study. Every letter maps to exactly one sound. Every pair shares one shape and differs only by direction, no irregular spelling exists because none has ever needed to. Stack that against two more real advantages this curriculum already has that a six-year-old first-grader doesn’t: cadets start at 12-13, years further into cognitive development, and each one gets individualized correction from their own Academy-tier AI rather than a single teacher’s attention split across a full classroom. A year producing full literacy isn’t a stretch given all this, it’s the conservative outcome, real six-year-olds do it on a noisier system with none of these advantages.

**What**** ****“****learning an alphabet before anyone tries to write a sentence with it****”**** ****actually means.** Real transparent-orthography readers hit fluent decoding “before the end of the first school year,” not on day one, the fluency lands late, after an earlier stretch of pure letter-recognition. Read the Year 1 bullet’s own framing the same way, an early alphabet-only phase giving way to real reading in the back half of the year, not a claim that cadets never move past the alphabet at all.

**Closing the letter gap.** The Nine cover 6 of 21 letters outright, which looks like a hole. But the direction-reversal rule the Nine already teach (the Third Pattern traced one way is T, reversed is D, the Fourth Pattern) is the exact trick every remaining consonant pair reuses. Once a cadet has that rule, the real teaching load isn’t 21 independent shapes, it’s 15: 5 vowel shapes, 6 consonant-pair shapes (learn one direction, the reverse is free), and 4 unpaired consonants, of which 6 are already covered by the Nine. Nine new shapes close the alphabet, not fifteen new letters.

- **Act 1 (Ch.1-12, Jan-Mar).** The Nine land here, covering AH, EH, T, D, W, L outright (6/21), and, more importantly, teaching the direction-reversal rule itself through the Third/Fourth pair. Everything after this act is that same rule, reapplied.

The rest of the act shifts from letter-recognition to connected-text decoding, actual words and short sentences, the exact point where the Year 1 bullet’s “before anyone tries to write a sentence with it” resolves.

By book’s end, cadets are functionally literate, reading Common Script signage, coursework, and messages without difficulty, not native-fluent (real readers keep improving for years past this point too), but the illiteracy constraint is fully closed by the time Book 1 ends.

## The childhood peg-game — playable rules (v3, 2026-08-15, playtested and corrected against Ch.2 directly)

*Revision history: the first draft of this section (same date, earlier pass) had a real, provable flaw, an unrestricted board lets the first player’s opening trace fork into more simultaneous winning completions than the second player can block in one move. Gemini ran the actual math on this, unprompted, as an outside playtest, and proposed three candidate fixes. Maxime playtested two of them by hand, Continuous Circuit and a reactive Closing Defense, and got a genuine eleven-turn tactical match out of it, the**** ****“****aha****”**** ****ending being P1 losing because their own required defensive trace would have crossed a line they themselves laid on turn one, a real zugzwang, not a scripted one. v2 (same day) corrected that ruleset against Ch.2 twice more, Reach now requires a genuine corner (****“******the first one with a corner in it******”****), and the old**** ****“****the Fourth Pattern is illegal****”**** ****framing was retired, Ch.2 never states a rule there, only an unexplained avoidance.**** ******v3, this pass, on Maxime’s direct request to check the whole ruleset against canon rather than just the two spots already caught:****** ****reread Ch.2’s Second Pattern description closely and found the Hold mechanic was wrong. The chapter shows Trav’s mother actually laying the Second Pattern down as a real move (****“******my mother used to put it down and then sit back off the board with her arms crossed and wait******”****) repeatedly, not declining to move. The earlier draft had modeled Hold as a once-per-game skip, that’s not what’s on the page. Corrected: Hold is now an ordinary, unlimited tactical choice, drawing a non-threatening trace on purpose, not a limited-use pass, and the**** ****“****Stuck****”**** ****ruling’s reference to it was cleaned up to match. Also added explicit Block/Trap/Wall naming (Sixth/Seventh/Eighth Patterns’ folk terms) for when those shapes occur naturally, since the physical game should teach the same vocabulary the books do rather than staying silent about it, and a flavor line for the**** ****“****let the younger kid open****”**** ****custom Ch.2 mentions directly. One piece remains deliberately invented rather than textually sourced: Continuous Circuit itself. Nothing in Ch.2 states the childhood game required a single unbroken snake per player, that constraint exists because removing it reopens the exact fork exploit Gemini found. Flagging this plainly rather than overclaiming it’s all canon-sourced, everything else in this section now is. This section matches, and summarizes, the two standalone rulebook documents (MYSTIC TRACE: THE RUNE GAME / TRACÉ MYSTIQUE: LE JEU DES RUNES), which are the canonical text going forward, keep the three in sync if any changes again.*

**Board and materials.** Same nine-peg board, 7-8-9 / 4-5-6 / 1-2-3. Two players, two colors.

**The opening.** Every game starts the same way, matching Ch.2 exactly: Player One’s first trace is always 7->1, the First Pattern, “start.” Player Two’s first trace is free, any peg to any other open peg. Ch.2’s own custom, worth keeping as flavor: when an older kid plays a younger one, the older kid lets the younger one open, “it’s the only move in the whole game that nobody can lose with.”

**The Circuit.** After a player’s first trace, every later trace they draw must begin at the endpoint their last trace ended on. Each player’s own lines become one continuous path rather than scattered threats, this is the actual fix for the fork problem, and it’s a deliberate reuse of the lore’s own definition of a Circuit, “multiple linked patterns read in sequence,” now literally embodied as a game mechanic instead of only a term. **Not textually sourced, flagged honestly:** Ch.2 never states the folk game required this, it’s the one deliberately invented piece of this ruleset, kept because dropping it reopens the fork exploit.

**The no-crossing rule.** A trace can never cross a trace already on the board, from either player. Not a house rule bolted on for balance, it’s the same physical constraint already established for the Ninth Pattern, a real hand or a real string can’t pass through a line that’s already there. It’s also what keeps the Circuit rule from trapping a player forever, and what ends the game in finite time.

**Reach, the win condition.** Complete an open, two-trace bend through three pegs, own color, with a genuine corner in it, not a straight line stretched across three pegs end to end, Ch.2’s own language for what makes the Third Pattern special is “the first one with a corner in it,” and nothing closing the shape into a triangle. Call it the moment it’s traced.

**The Shield, closing defense.** A Reach doesn’t win outright. The opponent gets exactly one turn to draw the trace that closes the shape into a triangle, drawn from wherever it needs to come from, the one move in the whole game exempt from the Circuit rule. If they close it legally, the Reach is dead and play continues, their own Circuit resumes next turn from wherever it actually left off, not from the defensive trace. If the closing trace would cross a line already on the board, they can’t play it, and the Reach stands: win.

**The Knot.** Three or more of a single player’s own traces meeting at one peg locks that peg, permanently, for both players, for the rest of the game. Under the Circuit rule this can’t happen from three separate opening spokes anymore, a player’s own path only touches most pegs twice (in, out). It still happens naturally when a path loops back through an already-visited peg, especially the center, which reaches every other peg by a straight line, as long as the new trace doesn’t cross anything already down. Kept as the game’s “expert” mechanic.

**Naming the shapes: Block, Trap, Wall.** Not separate rules, just recognition. A Knot that’s three lines rising to meet the top-center peg is a Block, the Sixth Pattern’s folk name for the game’s classic aggressive shape. Three lines dropping to meet the bottom-center peg instead is a Trap, the Eighth Pattern’s name, Block’s mirror image. Three traces in a row boxing off one whole edge of the board without closing anything is a Wall, the Seventh Pattern’s name, a stalling shape that doesn’t win by itself but can pen an opponent in behind lines they can’t cross. Calling these out by name when they occur is new to this pass, added so the physical game teaches the same vocabulary the books do instead of collapsing it into anonymous strategic play.

**Hold, corrected 2026-08-15.** Not a limited-use pass, that was wrong, corrected against Ch.2 directly. Any turn, a player may draw a trace that deliberately doesn’t threaten a Reach, sitting on what they’ve got and daring the opponent to come at it, exactly what Trav’s mother does with the Second Pattern in Ch.2, repeatedly, not once. Ordinary play, not a special power, doesn’t run out.

**Stuck.** If every legal move from a player’s current position would cross an existing line, they say so and skip that turn, free. Play continues until someone wins, or the whole board locks up.

**End of game.** Board full, no legal moves anywhere, nobody’s won: count knots, most knots wins, equal knots is a draw, “the board holds.”

**Tier/complexity:** circuit, first genuinely useful non-combat utility rune-form, good Year 2-3 candidate **Taught:** general curriculum, not path-specific, the kind of thing every cadet ends up using constantly outside class (footlockers, storage hatches, personal gear) **Effect:** Locks a physical or system-level access point until traced correctly again. **Form:** a Loop, 7->9->3->1->7, with one deliberate gap, the final connection back to the start peg only completes if the preceding four pegs were struck in the exact right order. Reads as a closed shape with one visibly weaker joint, the same design logic as a real physical padlock, the vulnerable point is intentional and load-bearing, not a flaw. **Notes:** Ordinary, low-stakes, exactly the kind of small mundane rune-form that makes the system feel lived-in rather than only ever mattering during a crisis. **Tier/complexity:** circuit, gets meaningfully more sophisticated Years 3-4 per the curriculum note above **Taught:** repair/diagnostic track, directly tied to the already- locked Years 3-4 emphasis (injury arc, Books 3-4) **Effect:** Temporary structural repair, holds a damaged system or mech-plate together without full replacement. **Form:** retraces an existing, already-damaged trace’s path a second time, laid directly beside the original rather than replacing it. Visually a doubled line, the second stroke run right up against a break in the first. The repair is legible as a second line holding the original’s shape, not erasing or replacing what broke. **Notes:** Unforced echo of the found-family device already running through the weekend chapters, worth leaving alone on the page rather than pointing at, the shape does the work without anyone needing to say so.

### Heirloom-tier circle-constructs (teleport, ethereal restraint)

**Tier/complexity:** circle, extreme end, outside the standard grammar **Taught:** never formally taught outside Sovereign/Heirloom-grade access **Effect:** Already locked in Qiraki_Concept.md’s Heirloom-pilot section, battlefield-scale teleport and restraint effects, hits friend and foe alike. **Form:** deliberately does not resolve to a clean peg/trace/knot description the way everything above it does, and that’s the actual point rather than an oversight. A Heirloom-tier rune-form requests a peg position the board’s real, physical geometry doesn’t have a slot for, and gets it honored anyway. Every rune-form up to this tier is a child asking reality a question using an honest, fixed vocabulary, nine real points, straight lines, nothing hidden. This tier is the same vocabulary used to ask for something that vocabulary was never actually built to grant. That’s the mechanical version of “no rune masters,” below Heirloom tier mastery means getting faster and cleaner at asking correctly, at this tier the question itself stops being a fair one, and no amount of cadet skill closes that gap, only wealth-gated hardware does. **Notes:** Worth formally writing this up as an actual on-page moment once a Heirloom-pilot scene gets drafted, a cadet or Synker watching one traced for the first time and recognizing that it’s using the same board they grew up on to do something the board was never supposed to be able to do.
